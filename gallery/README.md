# Gallery

These examples show how `$biorender-mechanism-figures` turns biomedical content into publication-style schematic prompts. The examples are designed for GPT Image models or similar image-generation tools.

| Example | Use Case | Best For |
| --- | --- | --- |
| [Tumor Immune Microenvironment](./examples/tumor-immune-microenvironment.md) | Mechanism figure | Oncology, immunotherapy, tumor microenvironment reviews |
| [Neuroinflammation Cascade](./examples/neuroinflammation-cascade.md) | Review schematic | Neuroscience, microglia, blood-brain barrier figures |
| [Gut Microbiome Metabolite Axis](./examples/gut-microbiome-metabolite-axis.md) | Graphical abstract | Microbiome, metabolism, host signaling |
| [Antibody-Drug Conjugate Mechanism](./examples/antibody-drug-conjugate.md) | Drug mechanism | Pharmacology, translational medicine, oncology therapy |
| [Single-Cell Multiomics Workflow](./examples/single-cell-multiomics-workflow.md) | Experimental workflow | Methods figures, grant schematics, study design |
| [JAK-STAT Pathway Review](./examples/jak-stat-pathway-review.md) | Pathway diagram | Immunology, cytokine signaling, review articles |

## Suggested Use

1. Copy an example prompt.
2. Replace the topic-specific molecules, cells, and labels with your own.
3. Generate a first image.
4. Iterate with the included refinement prompts, especially for label spelling and arrow direction.
